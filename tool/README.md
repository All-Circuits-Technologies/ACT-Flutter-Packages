## Presentation

This folder contains useful tools to work with flutter applications or with the packages.

It also contains the `ci.sh` script which is generated by the `mono_repo` package.

_`mono_repo` generates the package in a `tool` folder (that's why we don't name the folder
`tools`)._

## Scripts

Every script supports `--help`. They all expect to be called from the repository root.

### `pub_get_all.sh`

Calls `flutter pub get` in every package of the repository. It accepts another `flutter pub`
command as argument, for instance `upgrade`.

```console
> tool/pub_get_all.sh
```

### `test_all.sh`

Calls `flutter test` in every package which has a `test` folder, and prints the list of the
packages which failed. The packages without a `test` folder are skipped, because `flutter test`
fails when the folder doesn't exist.

```console
> tool/test_all.sh
```

A package whose tests only run on one platform says so next to the test task of its
`mono_pkg.yaml`, for instance `- test: --platform chrome`; the script reads those arguments from
there, so it runs the tests the same way the CI does.

Like `pub_get_all.sh`, it accepts `--use-fvm` to call `fvm flutter` instead of `flutter`.

### `mono_repo_generate.sh`

Regenerates the GitHub Actions workflows and `ci.sh` from the `mono_pkg.yaml` files, and applies
the patches the generated files need. It has to be called after any change made to a
`mono_pkg.yaml` file, and its output has to be committed.

```console
> tool/mono_repo_generate.sh
```

### `shellcheck_all.sh`

Runs `shellcheck` on every shell script of the repository and reports the scripts which do not
pass the check.

### `generate_png_variants.sh`

Generates the sized PNG variants of one or several images. It requires ImageMagick.
